## Checker Failure Contract

The checker must fail with actionable text when a required section is missing, when a repo-area row omits a required path marker, when a required path is not tracked or trackable, when a command baseline is missing an S02-S07 owner marker, when a command baseline is missing an exit or timeout result, when the dependency audit command claims a pass before QA-003 records S04 closure, when the outdated command claims a pass before QA-004 records S04 closure, when QA-005 does not record S05 closure, when QA-005 omits any required behavior/auth/install evidence marker, when QA-006 does not record S06 closure, when QA-006 omits executable docs parity evidence, when QA-006 does not classify migration-inventory Bun references as historical context rather than current setup guidance, when a finding lacks an S02-S07 owner, when a finding contains an unresolved placeholder, or when a local-only ignored path is used as a required fixture.

Checker output must not print environment values, API keys, secure-store contents, raw npm local install locations, or raw git diff contents.
